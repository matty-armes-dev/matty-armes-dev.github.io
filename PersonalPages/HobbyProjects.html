Hobby Projects

In my spare time when I have the energy to expend on extra things. I like to build various things digital or physical. I use these projects to try learning different aspects I've not had the chance to explore.

Godot Learning

My current interest is learning Godot. The engine strikes me as something quite wonderful with it's small footprint, very fast iteration cycle, and fleshed out features. I can imagine this becoming a key engine that will see use in a variety of A or AA games coming up in our near future.

Sandbox Engine

The Sandbox Engine is a C++ project I spun up with the intention of creating a framework for me to experiment with different game features. The initial intention was to build an imitation game system where each game was a "game card" I could develop. I built the engine using GLFW, GLM, and ENTT. Building the engine primarily designed around an entity component system has been a fun experience. There are aspects of it I have enjoyed and some parts which feel like the ECS wasn't a sensible decision for such low level engine systems. Overall however, I've liked working on this and I enjoy returning it when I get the time.
